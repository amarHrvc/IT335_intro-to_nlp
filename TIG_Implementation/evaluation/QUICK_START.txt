TROUBLESHOOTING:

  Problem: "FileNotFoundError: validation_cleaned.csv"
  Solution: Make sure TravelPlanner_cleaned folder exists 2 levels up
           Script will fallback to TravelPlanner/validation.csv if needed

  Problem: "ModuleNotFoundError: pandas"
  Solution: pip install pandas

  Problem: "ModuleNotFoundError: spacy"
  Solution: pip install spacy
           python -m spacy download en_core_web_sm

  Problem: Script takes forever
  Solution: Edit evaluate_parser.py, change sample_size=50 to sample_size=10

CODE STRUCTURE (evaluate_parser.py):

  1. Import libraries (pandas, json, datetime)
  2. ParserEvaluator class:
     - __init__()               → Setup
     - load_validation_data()   → Load CSV
     - evaluate_single_query()  → Parse and check one query
     - check_destination()      → Compare destination field
     - check_duration()         → Compare duration field
     - check_budget()           → Compare budget field
     - check_people()           → Compare people field
     - run_evaluation()         → Main workflow
     - display_results()        → Show results in console
     - save_results()           → Save 3 files
  3. main() function → Creates evaluator and runs it
